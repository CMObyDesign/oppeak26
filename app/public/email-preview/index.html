Source-of-truth templates live at email-templates/ in the repo. This preview folder is a copy so Cloudflare Pages can serve renderable HTML. When you edit a template in email-templates/, run cp email-templates/*.html app/public/email-preview/ before pushing so the preview stays in sync. All greetings use a bare {{contact.first_name}}: HighLevel supports neither Liquid pipe fallbacks nor Handlebars {{#if}} blocks on merge fields, so fallback must happen upstream (require first_name on opt-in, or set a workflow customValue default). See email-templates/README.md.
