# CFO By Design — Tiered SWOT Assessment Funnel

This project powers a three-tier diagnostic funnel for CFO By Design, a fractional CFO brand serving businesses above $2M in revenue. The free Health Check, the $47 Full Diagnostic, and the $297 Business Growth Analysis are generated by Claude via a Cloudflare Worker that scores intake answers, writes report content back to HighLevel custom fields, and (for the BGA tier) powers a strategist console (BGA Copilot) that drives the post-call growth plan to the customer.

## Two deploy targets, one repo

- **`worker/`** — Cloudflare Worker (backend): assessment scoring via
  Claude, GHL contact writeback, report hosting, Ask Solomon console.
  Deployed with `wrangler deploy`, per `wrangler.toml` at the repo root.
- **`app/`** — the funnel frontend the visitor actually sees, deployed
  separately as a Cloudflare Pages project with **root directory `app`**,
  build command `npm run build`, output directory `dist`. It POSTs to the
  worker and to HighLevel directly for lead capture/booking. See
  `app/README.md` for the full HighLevel-coupling notes and Cloudflare
  Pages setup.

## Setup

1. Clone the repository and enter it:
   - `git clone <repo-url>`
   - `cd oppeak26`
2. Install dependencies (if/when `package.json` is added):
   - `npm install`
3. Configure Cloudflare Worker variables and secrets:
   - Secrets:
     - `ANTHROPIC_API_KEY`
     - `GHL_API_KEY`
   - Non-sensitive variables (also committed as defaults in `wrangler.toml`, and overridable per environment):
     - `GHL_LOCATION_ID`
     - `BOOKING_LINK_47`
     - `BOOKING_LINK_297`
     - `PAYMENT_LINK_47`
     - `PAYMENT_LINK_297`

## Run Worker Tests

Use Node's built-in test runner from the `worker/` directory. The full
suite covers tier prompts, GHL writeback, report render, normalization,
derived metrics, structured-finding validation, and every BGA Copilot
toolkit module:

```bash
cd worker && node --test tests/**/*.test.js
```

The orphaned pre-LLM scoring scaffold's self-test (`logic/scoring_logic.test.js`)
is not part of the production surface; see `logic/README.md`.

## Deploy Cloudflare Worker

1. Ensure Wrangler is installed and authenticated.
2. Configure `wrangler.toml` for this project.
3. Deploy:

```bash
npx wrangler deploy
```

## Three Diagnostic Paths

- **CRITICAL_EXPOSURE** (free: 5-12 / full: 14-28)
- **HIDDEN_LIABILITY** (free: 13-18 / full: 29-41)
- **UNTAPPED_CAPACITY** (free: 19-25 / full: 42-54)
- **REHAB_REQUIRED** (triggered by Q11_D regardless of score)
